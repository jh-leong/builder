# 图片放大预览

一个 Tampermonkey 用户脚本，支持在网页上通过 Alt + 左键点击图片进行放大预览，并提供图片切换、缩放、拖拽等功能。

## 功能特性

### 基础功能

- **快捷键触发**：Alt + 左键点击图片即可打开预览
- **鼠标滚轮 / 触摸板缩放**：支持鼠标滚轮进行图片缩放
- **拖拽移动**：支持鼠标拖拽和触摸拖拽移动图片

### 图片切换功能

- **前后切换**：支持在页面上的多张图片之间切换浏览
- **缩略图预览**：底部显示图片缩略图，点击可快速切换
- **多种切换方式**：
  - 点击左右切换按钮
  - 点击底部缩略图
  - 使用键盘左右箭头键（← →）

### 图片编辑功能

- **旋转**：工具栏旋转按钮，每次旋转 90 度
- **水平翻转**：工具栏 X 轴翻转按钮
- **垂直翻转**：工具栏 Y 轴翻转按钮
- **恢复默认尺寸**：工具栏恢复按钮或双击图片

### 关闭方式

- 点击背景蒙层关闭
- 按 ESC 键关闭

## 使用方法

1. 安装 Tampermonkey 浏览器扩展
2. 在 Tampermonkey 中新建脚本，复制 `image-preview.user.js` 的内容
3. 保存脚本后，在任意网页上使用 **Alt + 左键** 点击图片即可预览

### 操作说明

- **打开预览**：Alt + 左键点击图片
- **缩放图片**：鼠标滚轮或触摸板双指缩放
- **移动图片**：鼠标拖拽或触摸拖拽
- **切换图片**：点击左右按钮、点击底部缩略图，或使用键盘左右箭头键
- **关闭预览**：点击背景或按 ESC 键

## 兼容性

- 支持所有现代浏览器（Chrome、Firefox、Safari、Edge 等）
- 需要 Tampermonkey 或类似用户脚本管理器
