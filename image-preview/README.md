# 图片放大预览

一个 Tampermonkey 用户脚本，支持在网页上通过 Alt + 左键点击图片进行放大预览。

## 功能特性

- **快捷键触发**：Alt + 左键点击图片即可打开预览
- **鼠标滚轮缩放**：支持鼠标滚轮进行图片缩放（0.5x - 5x）
- **触摸板双指缩放**：支持触摸板双指手势进行缩放
- **拖拽移动**：支持鼠标拖拽和触摸拖拽移动图片
- **边界限制**：自动限制图片在可视区域内
- **多种关闭方式**：
  - 点击背景蒙层关闭
  - 按 ESC 键关闭

## 使用方法

1. 安装 Tampermonkey 浏览器扩展
2. 在 Tampermonkey 中新建脚本，复制 `image-preview.user.js` 的内容
3. 保存脚本后，在任意网页上使用 **Alt + 左键** 点击图片即可预览

## 技术实现

- 使用 CSS Transform 实现缩放和平移
- 支持鼠标和触摸事件
- 响应式设计，适配不同屏幕尺寸
- 初始缩放为 80%，避免图片过大

## 兼容性

- 支持所有现代浏览器（Chrome、Firefox、Safari、Edge 等）
- 需要 Tampermonkey 或类似用户脚本管理器
